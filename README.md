## 📌 About The Project

EduSphere is a modern Smart School ERP Management System designed to simplify and organize everyday school administration. It provides a centralized dashboard where different academic and administrative activities can be accessed through a clean and user-friendly interface.

The platform brings essential school management modules together, helping administrators manage student records, teachers, classes, attendance, fees, examinations, timetables, and other campus activities efficiently.

## ✨ Key Features

- 📊 **Dashboard:** Centralized school management dashboard.
- 👨‍🎓 **Student Management:** Manage student information and records.
- 🏫 **Classes & Sections:** Organize academic classes and sections.
- 👨‍🏫 **Teachers & Staff:** Manage school employees and staff details.
- 📅 **Attendance Management:** Organize and track attendance.
- 💰 **Fees & Payments:** Manage student fees and payment records.
- 📝 **Examinations:** Organize examination-related activities.
- 🕒 **Timetable:** Manage academic schedules.
- 📚 **Homework:** Organize homework activities.
- 📖 **Library:** Manage library operations.
- 🚌 **Transport:** Organize school transportation.
- 📢 **Notices & Events:** Manage school announcements and events.
- 📈 **Reports:** Access school-related reports.
- ⚙️ **Settings:** Manage system settings.

## 🚀 Getting Started

To explore the project:

1. Open the live demo link.
2. Explore the dashboard.
3. Navigate through the available modules.
4. Explore the different school management sections.

To run the source code locally, clone the repository:

```bash
git clone https://github.com/Sehgal1001/EduSphere-Smart-School-Management-System.git
```

Navigate to the project directory:

```bash
cd EduSphere-Smart-School-Management-System
```

Open `index.html` in your browser.

## 🎯 Project Objective

The main objective of EduSphere is to provide a simple and organized digital platform for school administration. It aims to reduce manual paperwork, improve information management, and make everyday school operations easier through a centralized ERP dashboard.
